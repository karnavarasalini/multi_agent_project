New to Celene? Start here

Celene turns one plain-English request into a complete Java Spring Boot project that is compiled, tested and repaired automatically.

1. What to ask

Click an example to fill the request box, or write your own.

  • Name what you are building, for example "Hotel Room Booking".
  • List the entities and their fields, such as Room (id, roomNumber, type).
  • Say which endpoints you need, such as CRUD or a special action.
  • Don't worry about covering everything. Celene asks follow-up questions and you can add suggestions before the build starts.

2. What happens after you click

  1. Requirements. Celene reads your request, lists the requirements and assumptions, and asks a few questions.
  2. Plan. It decides the entities, fields, endpoints and the list of files to write.
  3. Code. It writes every file: entities, repositories, services, controllers, tests, pom.xml and application.properties.
  4. Test. It compiles the project, runs the unit tests, then starts the app and calls its endpoints.
  5. Fix. If anything fails, it reads the error logs and repairs the code, for up to 5 rounds. If the build still fails, press Retry and Celene tries again with a different approach, without rebuilding from scratch.

3. What you get

  • A complete Maven Spring Boot project with entities, repositories, services and controllers.
  • JUnit and Mockito unit tests for the generated code.
  • The compile and test results, including how many tests passed.
  • A live check of the running API's endpoints.
  • A summary of what was built and any fixes that were needed, shown in the output box at the end. Allow a few minutes for a build.
